# Copy-Ready Prompt Templates

## Explain code
Explain this feature's data flow in simple terms. Name relevant files/functions. List assumptions and unclear points separately. Do not modify code.

## Diagnose only
Compare observed and expected behavior. Test the likely cause using evidence. Do not modify files. Give the smallest next verification step.

## Bounded change
Make the minimum coherent change for these acceptance criteria. Follow the allowed scope, run relevant checks, and report the diff, exact results, and limitations.

## Review diff
Review this diff without modifying it. Check correctness, regressions, security/data access, and missing tests. Report findings with evidence and severity.

Ask for assumptions, observable evidence, alternatives/trade-offs, and remaining uncertainty. Request concise rationale and verification steps rather than hidden chain-of-thought.
