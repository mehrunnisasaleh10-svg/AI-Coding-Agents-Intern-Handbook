# AI Coding Agents Intern Handbook

## Overview

This repository contains practical exercises and supporting reports completed while working through the *AI Coding Agents Intern Handbook*.

The work focuses on understanding AI-assisted software development through small, structured tasks, implementation, testing, debugging, code review, and evidence-based reporting.

## Repository Structure

Each page is organized in a separate folder containing the relevant implementation files, tests, documentation, and final report where applicable.

- **Page 01:** Coding Agent Demonstration
- **Page 02:** LLM Context and Memory
- **Page 03:** Agent Working Loop
- **Page 04:** Orchestration Demonstration
- **Page 05:** Multi-Agent Demonstration
- **Page 06:** Prompt Communication
- **Page 07:** Repository Workflow
- **Page 08:** Debugging, Review, and Evidence
- **Page 09:** Safety, Privacy, and Efficiency
- **Page 10:** Task Tracker Practice

## Testing and Verification

Test results and supporting evidence are included with the relevant page folders. Results are reported according to the available execution evidence.

## Project Organization

The repository keeps each exercise separate to make the source code, tests, documentation, and reports easy to review.
